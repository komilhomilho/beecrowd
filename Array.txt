# Arrays em C# - Resumo

==================================================
PROPRIEDADES
============

Length

* Retorna a quantidade de elementos.

Rank

* Número de dimensões do array.

LongLength

* Igual ao Length, porém retorna long.

==================================================
CLASSE ARRAY
============

Array.Sort(array)

* Ordena em ordem crescente.

Array.Reverse(array)

* Inverte a ordem dos elementos.

Array.Clear(array, inicio, quantidade)

* Define os elementos como o valor padrão.

Array.Copy(origem, destino, quantidade)

* Copia elementos para outro array.

Array.Clone()

* Cria uma cópia do array.

Array.IndexOf(array, valor)

* Retorna o índice da primeira ocorrência.

Array.LastIndexOf(array, valor)

* Retorna o índice da última ocorrência.

Array.Exists(array, condição)

* Verifica se existe um elemento que atende à condição.

Array.Find(array, condição)

* Retorna o primeiro elemento encontrado.

Array.FindAll(array, condição)

* Retorna todos os elementos encontrados.

Array.FindIndex(array, condição)

* Retorna o índice do primeiro elemento encontrado.

Array.FindLast(array, condição)

* Retorna o último elemento encontrado.

Array.BinarySearch(array, valor)

* Pesquisa binária (o array deve estar ordenado).

Array.Resize(ref array, novoTamanho)

* Altera o tamanho do array.

Array.Fill(array, valor)

* Preenche todo o array com um valor.

==================================================
LINQ (using System.Linq;)
=========================

Select()

* Transforma os elementos.

Where()

* Filtra elementos.

OrderBy()

* Ordena em ordem crescente.

OrderByDescending()

* Ordena em ordem decrescente.

First()

* Retorna o primeiro elemento.

FirstOrDefault()

* Retorna o primeiro ou o valor padrão.

Last()

* Retorna o último elemento.

LastOrDefault()

* Retorna o último ou o valor padrão.

Any()

* Verifica se existe algum elemento que satisfaça uma condição.

All()

* Verifica se todos satisfazem uma condição.

Count()

* Conta elementos.

Max()

* Retorna o maior valor.

Min()

* Retorna o menor valor.

Sum()

* Soma todos os elementos.

Average()

* Calcula a média.

Distinct()

* Remove elementos repetidos.

Contains(valor)

* Verifica se um valor existe.

Skip(n)

* Ignora os primeiros n elementos.

Take(n)

* Pega os primeiros n elementos.

Reverse()

* Retorna a sequência invertida.

ToArray()

* Converte para array.

ToList()

* Converte para List<T>.

Concat()

* Junta duas sequências.

Union()

* Une duas sequências removendo duplicados.

Intersect()

* Retorna apenas os elementos em comum.

Except()

* Retorna os elementos que existem em uma sequência e não na outra.

SequenceEqual()

* Compara dois arrays.

GroupBy()

* Agrupa elementos iguais.

Exemplo:
numeros.GroupBy(x => x)

Count(x => ...)

* Conta elementos que satisfazem uma condição.

Exemplo:
numeros.Count(x => x == 5)

==================================================
EXEMPLOS RÁPIDOS
================

Ordenar:
Array.Sort(vetor);

Ordem decrescente:
Array.Sort(vetor);
Array.Reverse(vetor);

Maior valor:
int maior = vetor.Max();

Menor valor:
int menor = vetor.Min();

Somatório:
int soma = vetor.Sum();

Existe?
bool existe = vetor.Contains(5);

Contar quantos 5 existem:
int qtd = vetor.Count(x => x == 5);

Existe algum par?
bool par = vetor.Any(x => x % 2 == 0);

Filtrar pares:
var pares = vetor.Where(x => x % 2 == 0);

Dobrar valores:
var dobro = vetor.Select(x => x * 2);

Remover repetidos:
var unicos = vetor.Distinct();

Agrupar iguais:
var grupos = vetor.GroupBy(x => x);

Converter para array:
.ToArray();

Converter para lista:
.ToList();
